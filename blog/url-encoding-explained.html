Have you ever copied a link that had spaces in it, only to paste it and see %20 everywhere? That's URL encoding in action.

The Problem with URLs

URLs can only be sent over the Internet using the ASCII character set. If a URL contains characters outside the ASCII set, or characters that have special meaning in a URL (like spaces, question marks, or ampersands), they must be converted into a valid format.

How it Works

URL encoding replaces unsafe ASCII characters with a "%" followed by two hexadecimal digits. For example:

Space ( ) becomes %20
Exclamation (!) becomes %21
Ampersand (&) becomes %26

Summary / TL;DR
  • URLs can only be transmitted securely across the Internet using the ASCII character set.
  • URL encoding converts unsafe characters (like spaces) into a "%" followed by hex digits.
  • A space character translates to "%20" when properly encoded.
